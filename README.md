# Гостиница «Сладкие сны»

Учебный сервис бронирования на PHP 8+, MySQL и Bootstrap 5. Вёрстка основана на предоставленном шаблоне.

## Данные для входа администратора

- Логин: `hotel123`
- Пароль: `adminHotel`

В базе данных пароль хранится только в виде хеша. Скрипт `scripts/create_admin.php` также позволяет создать или обновить учётную запись из терминала.

## Установка

1. Скопируйте папку проекта в `htdocs`, например `htdocs/hotel_sladkie_sny`.
2. Запустите Apache и MySQL в панели XAMPP.
3. Откройте phpMyAdmin (`http://localhost/phpmyadmin`) и импортируйте `database.sql`.
4. При необходимости скопируйте `config/config.local.example.php` в `config/config.local.php` и укажите параметры подключения к БД.
5. Откройте `http://localhost/hotel_sladkie_sny/`.
6. Для входа администратора перейдите по ссылке «Вход администратора» и используйте данные выше.

## Технические требования

- PHP 8.1 или новее с расширениями `pdo` и `pdo_mysql`.
- MySQL 8.0+ или совместимая MariaDB.
- Apache/Nginx либо встроенный сервер PHP для локального тестирования.

Для локального запуска без XAMPP из корня проекта можно выполнить:

```bash
php -S 127.0.0.1:8000
```

Затем откройте `http://127.0.0.1:8000`. Встроенный сервер PHP предназначен только для локальной разработки.
