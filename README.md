# Гостиница «Сладкие сны» — задания 3 и 4

Учебный сервис бронирования на PHP 8+, MySQL и Bootstrap 5. Вёрстка основана на предоставленном шаблоне.

## Функциональность

### Для гостя

- Просмотр каталога номеров.
- Серверная фильтрация по категории, диапазону цены и количеству мест.
- Выбор дат заезда и выезда в календаре.
- В календаре прошедшие даты и периоды одобренных бронирований недоступны для выбора в качестве дат проживания.
- Выезд в день начала следующего одобренного бронирования разрешён: дата выезда не входит в оплачиваемый период проживания.
- При отправке заявки сервер повторно проверяет корректность дат и отсутствие пересечения с одобренными заявками.
- Новые и отклонённые заявки не блокируют даты. Даты становятся занятыми после одобрения администратором.

### Для администратора

- Вход в закрытую панель управления.
- Просмотр заявок и фильтрация по статусу.
- Одобрение или отклонение новых заявок.
- Удаление заявок любого статуса.
- При одобрении сервер повторно проверяет период. Если номер на эти даты уже занят одобренной заявкой, статус не меняется.

## Данные для входа администратора

- Логин: `hotel123`
- Пароль: `adminHotel`

В базе данных пароль хранится только в виде хеша. Скрипт `scripts/create_admin.php` также позволяет создать или обновить учётную запись из терминала.

## Установка с нуля

1. Скопируйте папку проекта в `htdocs`, например `htdocs/hotel_sladkie_sny`.
2. Запустите Apache и MySQL в панели XAMPP.
3. Откройте phpMyAdmin (`http://localhost/phpmyadmin`) и импортируйте `database.sql`.
4. При необходимости скопируйте `config/config.local.example.php` в `config/config.local.php` и укажите параметры подключения к БД.
5. Откройте `http://localhost/hotel_sladkie_sny/`.
6. Для входа администратора перейдите по ссылке «Вход администратора» и используйте данные выше.

## Обновление уже установленного проекта задания 3

Повторно импортировать `database.sql` не нужно. Таблицы и поля, используемые заданием 4, уже есть в базе задания 3.

1. Скопируйте обновлённые файлы проекта поверх предыдущей версии, сохранив `config/config.local.php`.
2. В phpMyAdmin выберите базу `hotel_sladkie_sny` и один раз импортируйте `migration_task4.sql`.
3. Если пользователь `hotel123` уже существует, миграция обновит его пароль до `adminHotel`; если нет — создаст учётную запись.
4. Откройте страницу бронирования и панель администратора, проверьте работу календаря и кнопок.

Миграция добавляет индекс для быстрого поиска занятых периодов и учётную запись администратора. Новые таблицы не создаются.

## Сброс или создание учётной записи администратора через CLI

Находясь в корне проекта, выполните:

```bash
php scripts/create_admin.php hotel123 'adminHotel'
```

Скрипт создаёт администратора или обновляет хеш пароля, если логин уже существует.

## Как проверяется занятость дат

Период проживания рассматривается как полуоткрытый интервал `[заезд, выезд)`: день выезда не считается занятой ночью. Например, если одобренная заявка действует с 20 по 25 ноября, другой гость может завершить своё проживание 20 ноября, а следующий гость — заселиться 25 ноября. Пересечения между периодами при этом нет.

SQL-условие пересечения:

```sql
check_in < :new_check_out
AND check_out > :new_check_in
```

Проверка выполняется только для заявок со статусом `approved`. Операции создания и одобрения используют транзакцию и блокировку строки номера, чтобы параллельные запросы не одобрили два пересекающихся периода.

## Технические требования

- PHP 8.1 или новее с расширениями `pdo` и `pdo_mysql`.
- MySQL 8.0+ или совместимая MariaDB.
- Apache/Nginx либо встроенный сервер PHP для локального тестирования.

Для локального запуска без XAMPP из корня проекта можно выполнить:

```bash
php -S 127.0.0.1:8000
```

Затем откройте `http://127.0.0.1:8000`. Встроенный сервер PHP предназначен только для локальной разработки.

## Структура проекта

- `index.php` — каталог и серверная фильтрация.
- `order.php` — форма бронирования и серверная проверка дат.
- `availability.php` — JSON-данные для календаря занятости.
- `admin.php` — просмотр, одобрение, отклонение и удаление заявок.
- `login.php`, `logout.php` — авторизация и выход администратора.
- `includes/` — подключение к БД и вспомогательные функции.
- `config/` — настройки подключения.
- `database.sql` — создание БД и начальные данные для новой установки.
- `migration_task4.sql` — обновление существующей БД с задания 3.
- `scripts/create_admin.php` — создание или обновление администратора из CLI.
- `css/`, `js/`, `img/`, `fonts/` — ресурсы шаблона и календаря.

## Ограничение модели

В предоставленной базе каталог содержит по одной записи на категорию (`Стандартный`, `Студия`, `Люкс`). Поэтому занятость проверяется для выбранной записи каталога/категории. Если в дальнейшем потребуется учитывать несколько физических номеров внутри одной категории, понадобится отдельная таблица конкретных комнат и распределение заявок по ним.
